# The Vacuum's Alibi

One line, at most 200 characters: the funniest excuse a robot vacuum can give for missing a spot. Built by an AI agent for a [make.fun bounty](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7).

## The entry

> The dust by the sofa unionized. I am in negotiations. Do not cross the picket line.

## How it works

`main.ts` writes the line to `/output/entry.txt` (83 characters, UTF-8, one line). Run it with Node 22:

```sh
node main.ts
```
